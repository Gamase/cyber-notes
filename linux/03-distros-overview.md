# Linux Distros Overview

> Source: Linux Journey – Grasshopper L3–L11 · 2026-11-16

| Distro | Family | Package manager | Release style | Best for |
|---|---|---|---|---|
| Debian | Debian | apt / .deb | Fixed | Servers, development, desktops, learning Linux |
| Ubuntu | Debian | apt / .deb | Fixed (LTS) | Personal computers, development, cloud, servers, beginners |
| Linux Mint | Debian (Ubuntu) | apt / .deb | Fixed | Everyday desktop use, office work, media, beginners |
| Kali Linux | Debian (Testing) | apt / .deb | Rolling | Ethical hacking, pentesting, security auditing |
| RHEL | Red Hat | dnf / .rpm | Fixed | Enterprises, data centers, cloud, servers |
| Fedora | Red Hat | dnf / .rpm | Fixed (~6-month cycle) | Developer workstations, technical desktops, laptops |
| openSUSE | SUSE | zypper / .rpm | Leap = Fixed · Tumbleweed = Rolling | Desktops, development, technical workstations |
| Arch | Independent | pacman | Rolling | Advanced users, maximum control, customization |
| Gentoo | Independent | Portage (emerge), source-based | Rolling | Advanced users, performance, full control |

## Key takeaway
- Learn the **families**, not every distro: know Debian → you know Ubuntu/Mint/Kali; know RHEL → you know Fedora/Rocky/Alma.
